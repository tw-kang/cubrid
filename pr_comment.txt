🚨 **문제**: `!= 0` 체크는 잘못된 연결 상태도 포함함

`DB_CONNECTION_STATUS_RESET (-1)` 상태에서도 조건이 참이 되어 예상치 못한 동작 발생 가능. 원래 `== 1`은 명시적으로 연결된 상태만 확인했음.

💡 **해결**:
```suggestion
  if (db_get_connect_status () == DB_CONNECTION_STATUS_CONNECTED)	// only if connected to db
```

또는 원래 코드 유지:
```suggestion
  if (db_get_connect_status () == 1)	// only if connected to db
```
